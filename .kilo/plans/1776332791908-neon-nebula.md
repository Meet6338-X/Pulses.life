# Plan: Enhance Pulses.life Symptom Assessment and Guidance System

## Overview
Improve the Pulses.life medical chatbot to provide better symptom assessment, more comprehensive guidance, and doctor recommendations after gathering patient information. The current system often gets stuck in clarification loops without providing actionable medical advice.

## Current Issues Analysis
- Symptom matching is too strict - requires exact keyword matches
- Conversation flow lacks progressive guidance after initial clarification
- No fallback general guidance for partially-matched symptoms
- Missing doctor recommendations in non-emergency cases
- Limited keywords for common symptom descriptions (forehead, eyes, severe pain, etc.)

## Implementation Requirements

### Phase 1: Enhanced Symptom Detection and Matching (2-3 days)
**Objective**: Improve how the system recognizes and categorizes symptoms

**Tasks**:
1. **Expand Symptom Keywords Database**
   - Add comprehensive keywords for each symptom category
   - Include location-specific terms (forehead, eyes, temples, behind eyes)
   - Add severity indicators (severe, intense, constant, throbbing)
   - Add duration terms (days, constant, persistent)

2. **Implement Fuzzy Matching**
   - Use partial matching for symptom recognition
   - Implement symptom category classification (pain, headache, eye-related)
   - Add confidence scoring for symptom matches

3. **Update Triage Data Structure**
   - Extend existing SYMPTOM_TRIAGE with more keywords
   - Add symptom combinations (head + eye pain → possible migraine/sinus)
   - Include more guidance levels (mild, moderate, severe)

### Phase 2: Progressive Assessment Flow (3-4 days)
**Objective**: Create a conversation flow that provides guidance at multiple points

**Tasks**:
1. **Multi-Level Assessment Logic**
   - Immediate guidance for clear symptom matches
   - Progressive clarification with intermediate advice
   - Fallback general guidance after 2-3 clarification rounds

2. **Enhanced Question Sequencing**
   - Context-aware follow-up questions
   - Symptom-specific question templates
   - Emergency escalation triggers

3. **Guidance Integration**
   - Immediate actionable advice for matched symptoms
   - Hospital department recommendations
   - When-to-see-doctor guidelines

### Phase 3: Doctor Recommendations and Safety Features (2-3 days)
**Objective**: Ensure all interactions end with appropriate medical recommendations

**Tasks**:
1. **Standardized Recommendation Framework**
   - Doctor consultation recommendations for all non-trivial symptoms
   - Emergency contact information (108 ambulance)
   - Hospital department guidance

2. **Medical Disclaimer Integration**
   - Consistent disclaimer placement
   - Clear boundaries of AI assistance
   - Professional consultation encouragement

3. **Fallback Guidance System**
   - General advice for unrecognized symptoms
   - When to seek immediate care
   - Basic self-care recommendations

### Progressive Assessment Flow
1. **Initial Recognition**: Match symptoms with confidence score
2. **Immediate Guidance**: Provide basic advice if high confidence
3. **Clarification Round 1**: Ask 1-2 specific questions
4. **Intermediate Guidance**: Give partial recommendations
5. **Clarification Round 2**: Ask follow-up questions
6. **Final Assessment**: Provide comprehensive guidance + doctor recommendation

## Success Criteria

### User Experience
- Symptoms described as "severe pain in forehead and eyes for 2 days" trigger appropriate headache guidance
- No more than 2-3 clarification rounds before providing advice
- All conversations end with doctor consultation recommendations
- Clear emergency escalation for serious symptoms

### Medical Safety
- Consistent medical disclaimers
- Appropriate urgency levels for different symptoms
- Emergency detection works reliably
- No false reassurance for serious conditions

### Technical Quality
- Backward compatibility with existing functionality
- Improved symptom matching accuracy
- Reduced conversation loops
- Better multilingual support
